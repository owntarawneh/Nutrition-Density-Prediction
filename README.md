## 📌 Project Overview
This project focuses on predicting the **Nutrition Density** of various food items using machine learning techniques. By analyzing nutritional components like calories, fats, vitamins, and minerals, the model provides an estimate of how nutrient-rich a specific food is.

## 🗂️ Dataset
The analysis is performed on a comprehensive dataset compiled from multiple food groups. The features include:
- **Macronutrients**: Caloric Value, Fat (Saturated, Monounsaturated, Polyunsaturated), Carbohydrates, Sugars, Protein, Dietary Fiber.
- **Vitamins**: A, B1, B2, B3, B5, B6, B11, B12, C, D, E, K.
- **Minerals**: Calcium, Copper, Iron, Magnesium, Manganese, Phosphorus, Potassium, Selenium, Zinc.
- **Other**: Sodium, Water, Cholesterol.

The datasets were merged to increase the sample size and improve model accuracy.

## 🚀 Key Features
- **Data Preprocessing**: Handling missing values, feature scaling, and merging multiple data sources.
- **Exploratory Data Analysis (EDA)**: Visualizing nutritional trends and correlations.
- **Model Training**: Implementing regression models to predict nutrition density.
- **Evaluation**: Assessing model performance using standard metrics.

## 🛠️ Installation & Usage
1. **Clone the repository**:
   ```bash
   git clone https://github.com/owntarawneh/Nutrition-Density-Prediction.git
   cd Nutrition-Density-Prediction
   ```
2. **Install dependencies**:
   Ensure you have Python installed, then run:
   ```bash
   pip install pandas numpy scikit-learn matplotlib seaborn
   ```
3. **Run the Notebook**:
   Open `Nutrition density.ipynb` in Jupyter Notebook or Google Colab to explore the analysis.
